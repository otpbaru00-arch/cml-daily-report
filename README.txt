DAILY REPORT v3

Buka index.html dengan browser modern (Chrome/Edge/Firefox).

Kategori 1 - REPORT NEW DEPO
- Multi aset
- Warna tiap aset berbeda
- Nama aset, judul, nama/keterangan kolom editable
- Perhitungan sisa target dan target per hari otomatis
- Data tersimpan per aset dan periode

Kategori 2 - REPORT HARIAN ASET
- Input: Nomor, Tanggal, Nama Tele, ID Member, Kategori, Nominal, Keterangan
- Nomor dan tanggal otomatis
- Data auto-save ke browser dan otomatis masuk Arsip Harian berdasarkan tanggal
- Filter arsip berdasarkan tanggal dan kategori
- Pengurutan kategori A-Z/Z-A, tanggal, dan nominal
- Pencarian Nama Tele / ID Member / Keterangan
- Judul report, nama menu, daftar kategori, dan nama kolom dapat diedit

Catatan:
Data disimpan di localStorage browser/perangkat yang digunakan. Jika data browser dihapus, data lokal juga dapat terhapus. Untuk deployment produksi, disarankan menambahkan backend/database dan login.
